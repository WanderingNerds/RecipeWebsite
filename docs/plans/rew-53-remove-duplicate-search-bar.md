- **No Jira/Confluence tool access this session** — see "Jira issue" and "Confluence page" sections above. Proceeding from the ticket text supplied in the prompt as authoritative, per instructions.
- **Exact spacing value after removal (AC8: "adjust spacing... without excessive gap").** CSS margins on adjacent block-level siblings collapse to the larger of the two values, so removing `.hero__search` (which currently sits between `.hero__lede` and `.hero__actions` and contributes its own `margin-bottom: 1.5rem`) will very likely already collapse `.hero__lede`'s existing `margin-bottom: 2.25rem` with `.hero__actions`' existing `margin-top: 1.5rem` into a single ~2.25rem gap, which is comparable to the existing heading-to-lede spacing and shouldn't look broken. I'm not prescribing an exact new margin value up front — the Developer should visually check the rendered gap after removing the markup and, only if it looks excessive, trim `.hero__lede`'s `margin-bottom` and/or `.hero__actions`' `margin-top` (e.g., toward something in the ~1.5–2rem range) to tighten it.
